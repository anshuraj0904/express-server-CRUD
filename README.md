# A Basic Server with crud ops on an array of teas using express.


## Installation and Setup:-

```bash
npm init -y
npm i express
npm i -D nodemon
```

```package.json
 "scripts": {
    "start": "node index.js",
    "dev":"nodemon index.js"
  }

type: module  
```

# To run the server:-

```bash
node index.js  or   nodemon index.js(for auto reload)
```
